# HASOL 투자 엔진 - 성장 룰 (Growth Rules)

**최종 수정**: 2026-05-14
**버전**: v2.0 (루프 프로토콜 v2.0 기준)

---

## 핵심 목적

성장 룰 = **루프 실패 또는 기회 손실 시 생성되는 기계적 차단/포착 룰**

모든 루프 시작 전 이 문서를 읽어 동일 실수를 원천 차단한다.

---

## 루프 프로토콜 v2.0 기준

### Step 1: 시장 확인

**Rule 20260514-01**: 시장 판정 기준
- **GO**: 지수 상방 + VIX 안정 → 공격적 접근
- **SOFT_GO**: 부분 충족 → 보수적 접근 (필터 강화)
- **NO_TRADE**: 지수 급락 또는 VIX 급등 → 신규 편입 금지

**Rule 20260514-02**: NO_TRADE 판정 시 절차
- Step 2~5 생략
- 관찰만 수행
- 신규 Top3 생성 금지

---

### Step 2: 뉴스에서 종목 후보 찾기

**Rule 20260514-03**: 자금 유입 가능성 높은 뉴스 선정
- 실적 발표 (EPS Surprise ≥ 10%)
- 신규 계약/파트너십 (계약액 명시)
- 정책 변화 (규제 완화, 지원금 등)
- 기술 혁신 뉴스 (특허, 신제품)
- 기관/내부자 거래 신호 (13F, Form 4)

**Rule 20260514-04**: 촉매 강도 평가
- 매우 강함(5): 실적 깜짝 발표, 대형 계약
- 강함(4): 신규 파트너십, 정책 변화
- 중간(3): 기술 뉴스, 기관 매수
- 약함(1~2): 일반 뉴스

---

### Step 3: Top20 압축

**Rule 20260514-05**: 뉴스 신호 강도 점수
- 매우 강함(5): +40점
- 강함(4): +30점
- 중간(3): +20점
- 약함(1~2): +10점 이하

**Rule 20260514-06**: 기술적 신호 점수
- 거래량 폭증 (×300% 이상): +30점
- 이동평균 정렬 (상승 추세): +20점
- 지지선 돌파: +15점

**Rule 20260514-07**: 기관 수급 점수
- 기관 매수 신호: +25점
- 공매도 감소: +15점

**Rule 20260514-08**: 섹터 모멘텀 점수
- 주도 섹터: +20점
- 약세 섹터: -20점

**Rule 20260514-09**: 시총 규모 조정
- 1조 이상 대형주: -10점 (추가 상승 제한)
- 100억~1조 중형주: 0점
- 100억 이하 소형주: +10점 (변동성 높음)

**Rule 20260514-10**: Hard Filter (제외 기준)
- 전고점 돌파 후 과열 상태 제외
- 하락 시나리오가 명확한 종목 제외
- 촉매가 약하거나 돈이 붙을 이유 불명확 제외
- **실적 발표 72시간 이내 종목 제외 (리스크)**

---

### Step 4: 가격 검증

**Rule 20260514-11**: 감지가 정의
- 감지가 = 오늘 시장 개장 시 가격 (또는 전일 종가)
- 과거 데이터 사용 금지
- API에서 실시간 데이터 확인 필수

**Rule 20260514-12**: 목표가/손절가 설정
- 목표가 = 감지가 × 1.10 (10% 상승)
- 손절가 = 감지가 × 0.90 (10% 하락)
- R-Value = (목표가 - 감지가) / (감지가 - 손절가) ≥ 1.0

**Rule 20260514-13**: 기술적 신호 재확인
- 52주 고가 대비 현재 위치 확인
- 이동평균 (20/50/200일) 정렬 확인
- 거래량 추세 확인
- 옵션 IV (내재 변동성) 확인

---

### Step 5: 실행 판단 (Top3 선정)

**Rule 20260514-14**: Top3 선정 기준
- 상승 확률 Top3 (Step 4 검증 통과)
- R-Value ≥ 1.0 필수
- 최소 2개 이상의 하락 시나리오(Bear Case) + 반박 근거 필수

**Rule 20260514-15**: 절대 규칙
- 절대 5개를 초과하지 않음
- 신호 약하면 0개도 가능
- 확신 없으면 편입 금지

**Rule 20260514-16**: NO_TRADE 시
- 시장 판정이 NO_TRADE면 0개 선정 (신규 편입 금지)

---

### Step 6: 기록

**Rule 20260514-17**: 저장 위치
1. SQLite DB (`/home/ubuntu/hasol_engine.db`)
   - `market_sensing`: 시장 판정
   - `top20_candidates`: Top20 후보
   - `top3_final`: 최종 Top3
   - `audit_results`: 복기 결과

2. GitHub (`/home/ubuntu/hasol-invest-os`)
   - `loop_YYYYMMDD.md`: 루프 보고서
   - `audit_YYYYMMDD.md`: 복기 보고서
   - `growth_rules.md`: 성장 룰 (이 파일)

**Rule 20260514-18**: 기록 항목
- 루프 시작일
- 시장 판정
- Top20 (점수 포함)
- Top3 (상승 근거 + 하락 시나리오)
- 감지가
- 목표가/손절가

---

### Step 7: 복기

**Rule 20260514-19**: 복기 시점
- 3일 복기: 루프 시작 + 3일 후
- 7일 복기: 루프 시작 + 7일 후
- 14일 복기: 루프 시작 + 14일 후

**Rule 20260514-20**: 복기 내용
1. Top3 성과 분석
   - 진입가 vs 14일 최고가
   - 수익률 계산
   - 성공/실패 판정 (10% 이상 = 성공)

2. Top20 분석
   - "왜 Top3보다 더 오른 종목이 있는가?" 분석
   - 압축 로직 튜닝 필요 여부 판단

3. 놓친 대어 분석
   - "내가 놓친 대어(False Negative)가 있는가?" 분석
   - 필터링 로직 수정 필요 여부 판단

4. 실패 원인 분석
   - 왜 틀렸는가? / 왜 놓쳤는가?
   - 기계적 차단/포착 룰 생성

**Rule 20260514-21**: 성공 기준
- 루프 성공: Top3 중 1개 이상 10% 이상 상승
- 루프 실패: Top3 모두 10% 미만 상승
