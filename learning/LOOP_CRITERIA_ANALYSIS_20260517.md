## 【문제점 정리】

### 문제 1: 웹 신호와 Investing.com 데이터의 기준이 다름

**웹 신호 (명확한 기준)**
```
뉴스 → 촉매 → 가격 반응 → 리스크 평가 → 판단
```
- 각 단계마다 판단이 들어감
- 근거가 명확함

**Investing.com (기준 없음)**
```
RSI 높음 → Top 30 → 끝
```
- 판단이 없음
- 근거가 "RSI 높으니까"

### 문제 2: 두 데이터를 합칠 때 기준이 없음

**내가 한 것**
```
웹 신호 3개 + Investing.com 27개 = Top 20
```

**기준이 없는 이유**
- 왜 웹 신호 3개만 선택했나? (명확한 기준 있음)
- 왜 Investing.com 27개를 선택했나? (기준 없음)
- 두 데이터를 어떤 비율로 합칠 건가? (기준 없음)

### 문제 3: 판단이 기록되지 않음

**웹 신호 (판단 기록됨)**
- NVIDIA: "72시간 이내 제외 (리스크 > 수익)"
- ENPH: "상업용 제품 확대 (촉매 명확)"

**Investing.com (판단 기록 안 됨)**
- SLNO: "RSI 97.76 → Top 1" (왜?)
- HUM: "RSI 87.97 → 진입 가능" (왜?)
- FTNT: "RSI 85.33 → 진입 가능" (왜?)

## 【복기할 때 성장할 수 없는 이유】

### 현재 상황
```
루프 → 기록 (판단 없음) → 복기 → "맞았다/틀렸다" → 끝
```

**문제**: 판단이 없으니까 왜 틀렸는지 알 수 없음

### 성장하려면
```
루프 → 판단 기록 (왜? 어떻게? 리스크?) → 복기 → 
→ "왜 틀렸나?" → 성장 룰 생성 → 다음 루프 적용
```

**예시**:
- 루프: SLNO 진입 (판단: RSI 97.76, 촉매 불명확)
- 복기: SLNO -50% (실패)
- 분석: "촉매 불명확한 종목은 고위험"
- 성장 룰: "RSI 높아도 촉매 불명확하면 제외"
