## 【판단 기준 확정】

### 기준 1: 웹 신호 (뉴스 기반)
```
뉴스 → 돈이 갈 축 → 직접 수혜 티커 → 가격 반응 → 거래량 반응 → 리스크 평가 → 판단
```

```
RSI 높음 → "왜 올랐나?" → 뉴스 확인 → 촉매 파악 → 지속성 평가 → 리스크 검토 → 판단
```

```
각 종목마다 "왜 진입하는가?" 명확히 기록
```
